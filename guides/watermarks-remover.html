Watermarks Remover — Tẩy sạch Watermark Ẩn & Siêu dữ liệu AI

Công cụ loại bỏ chữ ký số vô hình, ký tự khoảng trắng mã hóa Unicode và siêu dữ liệu nguồn gốc (C2PA/EXIF) được nhúng trong văn bản, hình ảnh và tài liệu do các mô hình trí tuệ nhân tạo sinh ra. Viết hoàn toàn bằng Python Standard Library thuần, không phụ thuộc vào bất kỳ thư viện bên ngoài nào.

Mục đích chính Tẩy Sạch Dấu Vết AI Xóa ký tự vô hình Unicode (Zero-width), metadata C2PA và EXIF máy ảnh.
Điểm đặc biệt Zero pip (0 Dependency) Chỉ dùng thư viện chuẩn Python (stdlib), chạy ngay không cần cài đặt.
Chất lượng ảnh Giữ 100% Điểm Ảnh Bóc tách nhị phân container, không nén lại ảnh, không suy giảm chất lượng.
Cách dùng CLI & Local API python watermarks_remover.py text

1. Quy trình làm sạch Siêu dữ liệu 3 Tầng

Các mô hình AI hiện đại thường nhúng các dấu vết ẩn để định danh nguồn gốc. Watermarks Remover quét và khử các dấu vết này qua 3 tầng lọc chuyên sâu:

2. Bảng định dạng tệp tin & Phương pháp xử lý

Loại tệp tin Dấu vết ẩn thường gặp Phương pháp làm sạch
Văn bản (TXT, MD, Code) Zero-width space, homoglyph unicode hoán đổi chữ cái La-tinh sang Cyrillic. Chuẩn hóa Unicode chuẩn NFKC và xóa bỏ toàn bộ mã ký tự vô hình.
Hình ảnh (PNG, JPG, WebP) Dấu vân tay EXIF, khối thông tin sinh prompt, thông tin checkpoint model AI. Cắt gọt các chunk metadata nhị phân, bảo toàn 100% pixel gốc.
Tài liệu (PDF, DOCX) Thông tin Creator tag, lịch sử chỉnh sửa, XML metadata đính kèm. Giải nén vùng định dạng và xóa triệt để các trường thuộc tính XML ẩn.

3. Chạy trực tiếp không cần cài đặt thư viện (Zero pip)

Bash · Sử dụng dòng lệnh làm sạch file 
# Làm sạch văn bản chứa ký tự ẩn
python watermarks_remover.py text --input draft.txt --output clean.txt

# Làm sạch một thư mục ảnh AI (xóa cả chứng chỉ C2PA)
python watermarks_remover.py image --dir ./ai_generated_images/ --strip-c2pa
Bash · Chạy microservice API nội bộ 
# Khởi chạy dịch vụ API cục bộ siêu nhẹ trên cổng 5000
python watermarks_remover.py serve --port 5000

# Gửi tệp cần làm sạch qua curl
curl -X POST http://localhost:5000/clean -F "file=@photo.png" -o clean_photo.png
Ứng dụng bảo mật và quyền riêng tư

Bên cạnh việc tẩy dấu vết AI, công cụ này là giải pháp bảo mật dữ liệu xuất sắc trước khi phát hành tài liệu: loại bỏ tọa độ GPS, thông tin máy chủ và tên người dùng hệ thống vô tình bị lưu trong metadata của tệp tin.
