Watermarks Remover — Làm sạch Ký tự ẩn & Siêu dữ liệu AI cho Quyền riêng tư

Bộ kỹ năng và dịch vụ chuẩn hóa viết bằng thư viện tiêu chuẩn của Python (không phụ thuộc bên thứ ba) giúp phát hiện và bóc tách các dấu vết nhận diện nguồn gốc AI (AI provenance marks) khỏi văn bản, mã nguồn và tệp đa phương tiện thuộc quyền sở hữu của bạn.

Bảo vệ quyền riêng tư Tác giả: Guillaume Meyer Giấy phép: MIT Ngôn ngữ: Python 3.10+ GitHub Repository (25.4k+ ★)

1. Tổng quan: Đây là gì và giải quyết vấn đề gì?

Khi các nhà cung cấp AI lớn (như OpenAI, Google, Anthropic) sinh nội dung văn bản, hình ảnh, tài liệu hoặc mã nguồn, họ thường nhúng vào các dấu vết nhận diện nguồn gốc (AI Watermarks) ngầm:

  • Ký tự Unicode vô hình: Zero-Width Spaces (ZWSP), Zero-Width Joiner (ZWJ), các ký tự đảo chiều văn bản (BiDi overrides) hoặc ký tự thẻ Unicode (Tags) vô hình đối với mắt thường nhưng dễ dàng bị máy quét nhận diện.
  • Chữ ký thống kê phân bố token: Các phương pháp nhúng watermark xác suất như SynthID-Text của Google, Kirchenbauer green-list hoặc Aaronson EXP keyed-Gumbel.
  • Siêu dữ liệu tệp tin (File Metadata): Siêu dữ liệu C2PA Content Credentials, thẻ EXIF, XMP nhúng trong tệp ảnh, video và văn bản Office.

Watermarks Remover được phát triển nhằm mục đích bảo vệ quyền riêng tư và tính vệ sinh dữ liệu (hygiene) trên các nội dung mà bạn hoàn toàn sở hữu bản quyền, loại bỏ các ký tự rác tiềm ẩn nguy cơ gây lỗi biên dịch hoặc rò rỉ siêu dữ liệu ngoài ý muốn.

Kiến trúc dịch vụ Thin-client Agent Skill + Local Python Service
Phụ thuộc bên thứ ba 0 dependencies (Dùng thuần Python stdlib)
Cổng dịch vụ mặc định http://127.0.0.1:8765
Khả năng bóc tách Unicode ẩn, SynthID, C2PA, EXIF, XMP

2. Ba tầng dấu vết AI được xử lý

Dự án phân chia việc làm sạch dữ liệu thành 3 tầng kỹ thuật riêng biệt:

A

Tầng A: Ký tự Unicode ẩn & Khoảng trắng dị biệt (Deterministic)

Sử dụng thuật toán tiền định viết bằng Python để quét sạch toàn bộ các ký tự vô hình: Zero-Width Space (U+200B), Zero-Width Non-Joiner (U+200C), Zero-Width Joiner (U+200D), Word Joiner (U+2060), Byte Order Mark (U+FEFF), các ký tự điều khiển định hướng BiDi và dải Unicode Tags (U+E0000 - U+E007F).

B

Tầng B: Watermark Thống kê phân bố Token (Statistical Sampling)

Đối phó với các dấu vết xác suất như SynthID-Text hay Kirchenbauer green-list bằng hook rewrite_text.py hoặc prompt tái cấu trúc câu chữ mà vẫn bảo toàn 100% ý nghĩa nội dung ban đầu.

Files

Tầng Tệp tin: Làm sạch Siêu dữ liệu C2PA & Thuộc tính nhúng

Bóc tách toàn bộ khối manifest C2PA, siêu dữ liệu XMP, thẻ EXIF máy ảnh, trường tác giả trong tài liệu Office và các chunk nhúng trong container đa phương tiện.

3. Các định dạng tệp tin được hỗ trợ toàn diện

Nhóm tệp tin Định dạng mở rộng hỗ trợ Phương pháp xử lý
Hình ảnh PNG, JPEG, WebP, AVIF, HEIC, BMP, GIF, TIFF, SVG Xóa EXIF, XMP, C2PA JUMBF chunks, giữ nguyên chất lượng nén ảnh.
Văn bản & Mã nguồn HTML, Markdown, Plain Text, Code files (.py, .ts, .js, .json) Quét chuỗi byte trần loại bỏ Unicode không hợp lệ và bidi overrides.
Tài liệu văn phòng PDF, DOCX, XLSX, PPTX, EPUB, ODT Giải nén cấu trúc zip/XML, xóa trường Author, Company, Revision và C2PA stamps.
Âm thanh & Video MP4, MOV, M4A, M4V, WAV, MP3, FLAC Loại bỏ metadata atoms (moov/udta) và ID3 tags chứa dấu vết AI.

4. Hướng dẫn cài đặt & Khởi động dịch vụ

1. Khởi động dịch vụ nền Python (Local Service)

Yêu cầu Python 3.10 trở lên. Không cần cài bất kỳ thư viện pip nào bên ngoài:

bash 
# Clone repo
git clone https://github.com/guillaumemeyer/watermarks-remover.git
cd watermarks-remover

# Khởi động dịch vụ cục bộ trên cổng 8765
python3 service/server.py --port 8765

2. Cài đặt Skill cho Coding Agent

bash 
# Cài đặt tự động cho Claude Code
python3 install_skill.py --skill remove-ai-marks --target claude-code

# Cài đặt cho Cursor
python3 install_skill.py --skill remove-ai-marks --target cursor

# Cài đặt cho Codex
python3 install_skill.py --skill remove-ai-marks --target codex

5. Cách gọi trong phiên làm việc với Agent

Sau khi cài đặt, bạn có thể yêu cầu agent làm sạch tài liệu trực tiếp:

prompt 
Hãy dùng skill /remove-ai-marks để kiểm tra và làm sạch toàn bộ tệp trong thư mục docs/ và assets/images/.
Loại bỏ các ký tự Unicode vô hình và siêu dữ liệu C2PA/EXIF khỏi các file ảnh sản phẩm.
Kiến trúc Thin-Client

Bản thân tệp skill nạp vào agent hoàn toàn là Markdown thuần túy; nó chỉ gọi API HTTP cục bộ tới dịch vụ đang chạy trên cổng 8765. Do đó agent của bạn không bao giờ bị nghẽn context hoặc cần cài đặt môi trường Python nặng nề.

6. Lưu ý về Quyền sở hữu & Đạo đức sử dụng

Chỉ sử dụng trên nội dung bạn sở hữu

Công cụ này được thiết kế phục vụ mục đích bảo vệ quyền riêng tư cá nhân và làm sạch kỹ thuật cho các dữ liệu do bạn tạo ra hoặc bạn sở hữu bản quyền hợp pháp. Không sử dụng công cụ để vi phạm pháp luật, làm sai lệch bằng chứng hoặc đánh tráo nguồn gốc tác phẩm của người khác.
