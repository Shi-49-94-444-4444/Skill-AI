1. Bản đồ 8 Kỹ năng cốt lõi trong hệ sinh thái

Thay vì viết prompt thủ công nhắc nhở AI "hãy code tối ưu", Vercel Labs hệ thống hóa kiến thức kỹ thuật thành 8 skill chuyên biệt. Agent sẽ kích hoạt đúng ngữ cảnh khi phân tích hoặc viết mã nguồn:

Tên kỹ năng Mục tiêu kỹ thuật Quy tắc trọng tâm áp dụng
react-best-practices Tối ưu hiệu năng React & Next.js App Router Triệt tiêu Waterfall fetch, thu gọn bundle client, tách Server Component (RSC), kiểm soát render lặp.
web-design-guidelines Kiểm tra thiết kế và khả năng tiếp cận (a11y) 100+ checklist: tương phản màu WCAG AA, focus visible, vùng chạm mobile tối thiểu 44×44px, giảm chuyển động.
composition-patterns Kiến trúc component React sạch Áp dụng Compound Components, slot pattern, tách logic custom hooks, tránh prop drilling sâu quá 2 tầng.
next-cache-components Chiến lược bộ nhớ đệm (Caching) Tối ưu unstable_cache, React 19 cache(), On-demand Revalidation với revalidateTag.
turborepo Quản lý Monorepo quy mô lớn Tối ưu cache pipeline, xác định quan hệ phụ thuộc gói nội bộ workspace:*, cắt giảm thời gian build CI.
package-manager Xử lý xung đột gói phụ thuộc Chuẩn hóa giữa pnpm, Bun, yarn, npm; ngăn chặn phantom dependencies và khóa phiên bản lockfile an toàn.
view-transitions Chuyển cảnh mượt mà chuẩn native Tích hợp Browser View Transitions API vào Next.js App Router mà không làm giật khung hình (0 jank).
deploy-to-vercel Tự động hóa triển khai sản phẩm Liên kết project, cấu hình biến môi trường production, preview URL và kiểm tra Edge Config trước release.

2. Sơ đồ luồng Audit hiệu năng 4 bước

Khi phân tích một trang React/Next.js chậm, agent áp dụng quy trình kiểm tra tuần tự từ gốc rễ mạng đến lớp hiển thị giao diện:

3. Phân cấp độ ưu tiên của 40+ quy tắc & Kiểm tra a11y

Mức Critical (Bắt buộc sửa ngay) — Chặn nghẽn mạng & Treo giao diện

• async-waterfall: Tuyệt đối không gọi tuần tự các API độc lập trong Server Component.
• bundle-heavy-deps: Không import trực tiếp icon pack đồ sộ hoặc lodash không cherry-pick.
• server-client-leak: Không truyền secret key hoặc hàm server chưa qua sanitize xuống Client Component.

Mức High (Khuyến nghị cao) — Tối ưu tài nguyên & Chỉ số Web Vitals

• client-leaf-boundary: Đẩy ranh giới Client xuống sâu nhất có thể, không bọc 'use client' trên cả trang.
• image-lcp-priority: Hình ảnh trên màn hình đầu tiên (Above-the-fold) phải có priority để đạt chuẩn LCP < 2.5s.
• context-state-splatter: Tách state thường xuyên thay đổi ra khỏi context chứa state toàn cục.

Mức Medium (Hoàn thiện mã nguồn) — Clean Code & Khả năng duy trì

• compound-slots: Ưu tiên slot pattern thay vì truyền quá nhiều cờ boolean hiển thị.
• derived-state-memo: Tránh lưu state phụ thuộc vào props; tính toán trực tiếp hoặc memoize có chọn lọc.

Tương phản & Khả năng đọc (Contrast & Text)

Độ tương phản tối thiểu 4.5:1 cho văn bản thường và 3:1 cho văn bản lớn chuẩn WCAG AA. Hạn chế dùng font size dưới 12px.

Vùng chạm & Điều hướng phím (Touch Targets & Focus)

Mọi nút bấm và liên kết trên mobile phải đạt kích thước chạm tối thiểu 44×44px. Luôn có viền :focus-visible rõ ràng khi nhấn Tab.

Chuyển động & Trực giác (Motion & Layout)

Tôn trọng tùy chọn hệ thống prefers-reduced-motion: tắt toàn bộ animation nặng khi người dùng kích hoạt giảm chuyển động.
