1. Tổng quan: Đây là gì và giải quyết vấn đề gì?

Khi các lập trình viên sử dụng AI để xây dựng ứng dụng React và Next.js, mã nguồn do mô hình sinh ra thường mắc phải các lỗi hiệu năng phổ biến: hiệu ứng thác nước (waterfalls) trong fetch dữ liệu, re-render vô tội vạ, bỏ qua các chuẩn accessibility (ARIA, focus-visible) hoặc sử dụng các biến thể boolean prop cồng kềnh.

Vercel Agent Skills giải quyết bài toán này bằng cách đóng gói toàn bộ cẩm nang kỹ thuật nội bộ của Vercel (Engineering Guidelines, Design System Rules, Writing Handbook) thành các tập tin chỉ dẫn SKILL.md. Agent sau khi được nạp bộ skill này sẽ tự động kiểm tra mã nguồn, rà soát hiệu năng và đưa ra các đề xuất tái cấu trúc chuẩn xác nhất.

Quy chuẩn kỹ thuật Vercel Engineering Standards
Tối ưu React/Next.js 40+ quy tắc phân cấp mức độ
Kiểm tra giao diện (UI UX) 100+ bài kiểm tra Accessibility
Cơ chế phát hiện Tự động (Model-Invoked)

2. Chi tiết 8 kỹ năng cốt lõi trong bộ sưu tập

Mỗi kỹ năng trong kho này chịu trách nhiệm cho một miền chuyên môn độc lập:

Tên Kỹ năng (Skill) Mô tả nhiệm vụ Tình huống sử dụng
vercel-optimize Kiểm toán toàn diện dự án triển khai trên Vercel: chi phí, thời gian xử lý hàm Serverless/Edge, chiến lược bộ nhớ đệm (ISR), middleware, tối ưu ảnh và số phút build. "Giảm chi phí hóa đơn Vercel", "Tìm route bị chậm", "Kiểm toán hiệu năng dự án".
react-best-practices Bộ nguyên tắc vàng về hiệu năng React và Next.js. Ưu tiên giải quyết tình trạng waterfall fetch dữ liệu, phình to bundle size và re-render thừa thãi. Viết component mới, review code trước khi merge, tối ưu thời gian tải trang.
web-design-guidelines Soát xét mã giao diện theo hơn 100 tiêu chuẩn công nghiệp: ngữ nghĩa HTML, trạng thái focus, hỗ trợ bàn phím, tương thích reduced-motion, định dạng số/ngày tháng quốc tế. "Review my UI", "Check accessibility", "Audit design", "Check my site against best practices".
writing-guidelines Kiểm tra câu chữ, văn phong tài liệu kỹ thuật theo Vercel Writing Handbook: câu chủ động, không dùng từ cấm (như 'easy', 'simple'), chuẩn hóa code block và ngắt dòng. "Review my docs", "Check writing style", "Audit prose", kiểm tra chất lượng file README.
react-native-guidelines 16 quy tắc tối ưu cho React Native và Expo: sử dụng FlashList thay vì FlatList, Reanimated, safe areas, expo-image và mô hình quản lý state Zustand. Xây dựng ứng dụng di động đa nền tảng, tối ưu tốc độ cuộn danh sách lớn trên iOS/Android.
react-view-transitions Triển khai chuyển cảnh trang mượt mà chuẩn native thông qua React View Transition API và thuộc tính transitionTypes trên component next/link. Hiệu ứng list-to-detail morphing, chuyển cảnh trang theo hướng tiến/lùi, animated filter.
composition-patterns Mô hình cấu thành component React có khả năng mở rộng. Tránh tình trạng lạm dụng boolean prop bằng compound components và state lifting. Tái cấu trúc component thư viện, thiết kế API component linh hoạt, loại bỏ prop drilling.
deploy-to-vercel Tự động hóa quy trình triển khai lên Vercel: ưu tiên git-push deploy, gọi Vercel CLI hoặc tạo deployment tạm thời với link claim khi chưa đăng nhập. "Deploy my app", "Push this live", "Tạo bản preview deployment".

3. Điểm nhấn: 40+ Quy tắc tối ưu React từ Vercel

Vercel phân loại các tiêu chuẩn tối ưu theo mức độ ảnh hưởng trực tiếp đến trải nghiệm người dùng (Impact Levels):

!

Mức độ Nguy cấp (Critical) — Triệt tiêu Waterfall & Tối ưu Bundle Size

Tránh tình trạng component cha đợi dữ liệu xong mới đến component con fetch (fetch waterfall). Chuyển sang fetch song song với Promise.all hoặc nạp dữ liệu ở Server Component trước khi render. Phân tích loại bỏ các thư viện cồng kềnh (ví dụ thay thế Moment.js bằng date-fns hoặc Intl).

A

Mức độ Cao (High) — Hiệu năng Phía Máy chủ (Server-side Performance)

Tận dụng triệt để React Server Components (RSC) để giữ logic nặng và module phụ thuộc lớn ở máy chủ, không chuyển JavaScript xuống client. Áp dụng dynamic IO và Suspense boundaries hợp lý.

B

Mức độ Trung bình (Medium) — Kiểm soát Re-render & Kích thước DOM

Không đặt định nghĩa component lồng bên trong component khác. Sử dụng component con cô lập (isolated child) hoặc React Compiler/memo khi có tính toán nặng. Tránh inline object hoặc inline arrow function trong props nếu component con được memoize.

4. Điểm nhấn: 100+ Tiêu chuẩn Web Interface Guidelines

Kỹ năng web-design-guidelines trong bộ sưu tập này là một trong những công cụ audit toàn diện nhất hiện nay:

Trạng thái Focus Bắt buộc có :focus-visible rõ ràng, offset 2px, không dùng outline: none trần trụi.
Khả năng tiếp cận Thẻ ngữ nghĩa (main, nav, article), aria-label trên icon buttons, tỷ lệ tương phản đạt chuẩn WCAG.
Chuyển động (Motion) Luôn tôn trọng prefers-reduced-motion, chỉ animate transform và opacity để GPU tăng tốc.
Typography Sử dụng font-variant-numeric: tabular-nums cho bảng số liệu, tránh dùng ký tự 3 dấu chấm (...) thay cho ellipsis (…).

5. Hướng dẫn cài đặt & Kích hoạt

Cài đặt bộ skill này thông qua công cụ quản lý skills theo chuẩn Agent Skills:

bash 
npx skills add vercel-labs/agent-skills

Sau khi thêm vào dự án, các tệp chỉ dẫn sẽ nằm trong thư mục .agents/skills/ hoặc thư mục cấu hình của agent bạn đang sử dụng. Agent sẽ tự động nạp khi nhận thấy các câu lệnh hoặc ngữ cảnh liên quan.

6. Kịch bản ứng dụng thực tế

Kịch bản 1: Kiểm tra Accessibility và UX trước khi phát hành

prompt 
Hãy review lại file components/Navbar.tsx và components/DataTable.tsx theo web-design-guidelines.
Kiểm tra kỹ các trạng thái focus-visible, hỗ trợ điều hướng bằng phím Tab, aria-labels và chế độ dark mode.

Kịch bản 2: Tái cấu trúc loại bỏ Boolean Prop Hell

prompt 
Component Modal hiện tại đang nhận hơn 10 props boolean (hasHeader, isDismissable, showCloseButton, isFooterSticky...).
Hãy dùng composition-patterns để chuyển đổi sang mô hình Compound Components (Modal.Header, Modal.Body, Modal.Footer).
