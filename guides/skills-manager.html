Skills Manager — Bảng điều khiển Quản lý & Điều phối Kỹ năng Agent

Công cụ trực quan kết hợp CLI mạnh mẽ giải quyết bài toán quản trị kỹ năng khi số lượng skill trong máy vượt quá vài chục. Hỗ trợ tìm kiếm, cài đặt 1-click, đồng bộ kho skill và cô lập phạm vi hoạt động giữa Toàn cục (Global) và Từng dự án (Project Workspace).

Mục đích chính Quản Lý & Bật Tắt Skill Giao diện UI và CLI để bật/tắt, cập nhật và ngăn chặn ô nhiễm kỹ năng.
Tính năng cốt lõi Phân vùng Workspace Cô lập skill Global dùng chung và skill Project đặc thù cho từng repo.
Thao tác cài đặt 1-Click Install Duyệt kho trực tuyến và cài đặt ngay không cần nhớ đường dẫn git.
Hỗ trợ nền tảng Claude Code & Codex Đồng bộ tự động vào thư mục .claude/skills/.

1. Nguyên lý vận hành của Skills Manager

Thay vì chỉnh sửa thủ công các file cấu hình JSON hay sao chép thư mục kỹ năng rải rác trong máy tính, Skills Manager chuẩn hóa toàn bộ luồng nạp và giải phóng (nhấn vào ảnh để xem chi tiết):

// 02 · TÔ-PÔ PHÂN VÙNG WORKSPACE ĐƠN NGUỒN (ATOMIC SYMLINK MESH): Thư viện kỹ năng gốc liên kết tức thì trong 0.2ms tới 4 môi trường lập trình (Claude Code, Cursor, Antigravity, Codex) với 0 MB dư thừa ổ đĩa.

2. Mô hình phân vùng Workspace (Global vs Project-Scoped)

Điểm mạnh nhất của Skills Manager là khả năng ngăn chặn tình trạng "ô nhiễm kỹ năng" (Skill pollution) — nơi một kỹ năng chỉ dành cho Python lại bị kích hoạt nhầm trong một dự án Go hoặc Rust:

Phạm vi áp dụng Vị trí lưu trữ Loại kỹ năng phù hợp
Global Scope (Toàn cục) ~/.claude/skills/ hoặc ~/.config/agent/ Các kỹ năng phổ quát: Git conventions, TDD workflow, Code review, Linter chung, Quản lý tài liệu.
Project Scope (Theo dự án) ./.claude/skills/ trong thư mục mã nguồn Các kỹ năng công nghệ sâu: Next.js App Router rules, Django ORM best practices, Prisma migration scripts.
// 03 · QUY TRÌNH TRIỂN KHAI BỘ PRESET (PRESET INTEGRITY MANIFEST): Lệnh skills-manager deploy --preset frontend đồng bộ hóa 42 kỹ năng chuẩn mực được ký xác thực mật mã.

3. Giao diện Khám phá & Cài đặt 1-Click

Skills Manager tích hợp sẵn kho thư viện phong phú với khả năng lọc theo tag, tìm kiếm theo tên và hiển thị hướng dẫn chi tiết:

4. Sử dụng tiện lợi qua công cụ dòng lệnh (CLI)

Bash · Các lệnh CLI phổ biến 
# Liệt kê toàn bộ kỹ năng đang cài đặt trong máy
skills-manager list

# Cài đặt một kỹ năng từ GitHub vào dự án hiện tại
skills-manager add vercel-labs/agent-skills --scope project

# Bật hoặc tắt nhanh một kỹ năng mà không cần xóa thư mục
skills-manager disable taste-skill
skills-manager enable taste-skill
Giữ sạch ngữ cảnh cho Agent

Việc bật quá nhiều kỹ năng không liên quan cùng một lúc sẽ làm phình to system prompt và khiến agent dễ nhầm lẫn quy tắc. Hãy dùng Skills Manager để chỉ bật đúng bộ kỹ năng phục vụ cho công nghệ của dự án bạn đang làm việc.
