Skills Manager — Ứng dụng Desktop Quản lý & Đồng bộ Skill cho hơn 50 Coding Agent

Ứng dụng máy tính siêu nhẹ viết bằng Rust, giải quyết tình trạng phân mảnh skill giữa các công cụ AI lập trình: tập trung toàn bộ kỹ năng vào một kho duy nhất, đồng bộ một chạm qua hệ thống Presets, hỗ trợ phân loại phạm vi Global/Project và cho phép chính agent tự quản lý kỹ năng của mình.

Công cụ cho agent Tác giả: xingkongliang Giấy phép: MIT Ngôn ngữ: Rust / Tauri GitHub Repository (7k+ ★)
1. Tổng quan 2. Các tính năng cốt lõi 3. Mô hình Workspace & Presets 4. 50+ Coding Agent được hỗ trợ 5. Cài đặt & Sử dụng 6. Để Agent tự quản lý Skill 7. Tài liệu & Nguồn gốc

1. Tổng quan: Đây là gì và giải quyết vấn đề gì?

Khi sử dụng song song nhiều công cụ AI lập trình (như Claude Code trong terminal, Cursor trong IDE, GitHub Copilot trong VS Code, Codex hoặc Gemini CLI), lập trình viên phải đối mặt với một cơn ác mộng quản lý:

  • Mỗi công cụ lưu skill ở một thư mục khác nhau (~/.claude/skills, ~/.cursor/skills, ~/.agents/skills, .github/copilot-instructions.md...).
  • Khi bạn tinh chỉnh hoặc cập nhật một skill, bạn phải sao chép thủ công qua hàng chục thư mục.
  • Không có cách nào bật/tắt nhanh một nhóm skill cho một dự án cụ thể mà không làm ảnh hưởng các dự án khác.

Skills Manager ra đời để gom tất cả về một thư viện trung tâm duy nhất (Single Source of Truth), phân bổ tự động bằng liên kết tượng trưng (symlink) hoặc copy có kiểm soát, đi kèm giao diện đồ họa đẹp mắt và mượt mà.

Nền tảng công nghệ Rust + Tauri (Siêu nhẹ, tiêu tốn dưới 50MB RAM)
Thư viện trung tâm Thư mục ~/.skills-manager
Hỗ trợ chợ ứng dụng skills.sh Marketplace + Git URL + Local zip
Phạm vi công cụ 50+ AI Coding Runtimes & IDEs

2. Các tính năng cốt lõi

Tính năng Khả năng kỹ thuật Lợi ích thực tế
Unified Skill Library Tập hợp tất cả skill từ Git repos, folder cục bộ, file nén .zip, .skill hoặc marketplace về thư mục trung tâm. Chỉ cần chỉnh sửa file một nơi, tất cả các agent đều được hưởng cập nhật mới nhất.
Hệ thống Presets Gom các skill thành bộ theo mục đích: "Frontend Next.js", "Backend Go", "Security Audit". Bật/tắt nguyên bộ bằng một cú click. Chuyển đổi ngữ cảnh làm việc trong 1 giây mà không làm phình to context của agent.
Nhận diện định dạng tự động Tự động phân tích cấu trúc để nhận diện chuẩn Agent Skills, Claude Plugin, Copilot Extension hay Cursor Rules. Không lo lắng về sự khác biệt cú pháp giữa các hãng AI.
Chợ kỹ năng tích hợp Tìm kiếm và duyệt hàng nghìn skill phổ biến từ skills.sh ngay trong ứng dụng desktop mà không cần mở trình duyệt. Cài đặt một chạm kèm kiểm tra tương thích trước khi nạp.

3. Mô hình Workspace: Global vs Project Scope

Skills Manager phân chia phạm vi áp dụng rất khoa học:

Phạm vi Toàn cục (Global Workspace) Áp dụng cho các kỹ năng cá nhân dùng mọi lúc, mọi nơi: kỹ năng giao tiếp, phong cách viết lách, công cụ debug cơ bản. Tự động có mặt trên mọi dự án của agent.
Phạm vi Dự án (Project Workspace) Chỉ kích hoạt khi mở đúng thư mục của dự án đó: quy tắc thiết kế DESIGN.md của công ty, bộ skill Docker/K8s riêng biệt, tiêu chuẩn mã nguồn của repo.

4. Hơn 50 Coding Agent & Môi trường được hỗ trợ

Skills Manager tự động phát hiện các công cụ đã cài đặt trên máy tính của bạn:

  • Terminal Coding Agents: Claude Code, Codex CLI, Gemini CLI, OpenCode, Aider, OpenClaw, Hermes Agent...
  • IDE & Biên tập mã: Cursor, VS Code (GitHub Copilot), Windsurf, JetBrains AI Assistant, Zed Editor...
  • Agent Harness & Nền tảng mở: DeepSeek Harness, Cindy, Adal, Continue.dev, Cline...

5. Hướng dẫn cài đặt & Thiết lập

1. Tải ứng dụng Desktop

Truy cập website chính thức skillsmanager.dev để tải bộ cài đặt phù hợp với hệ điều hành (macOS, Windows, Linux).

2. Cài đặt nhanh qua dòng lệnh / Package Manager

bash 
# macOS (Homebrew)
brew install --cask skills-manager

# Windows (Winget)
winget install xingkongliang.SkillsManager

# Linux (Cargo)
cargo install skills-manager-cli

6. Để Agent tự quản lý kỹ năng qua CLI / API

Thay vì bạn phải tự click chuột, bạn có thể cấp quyền cho chính Claude Code hoặc Cursor gọi Skills Manager:

prompt 
Dự án này là một web thương mại điện tử viết bằng Next.js.
Hãy dùng skills-manager CLI để kiểm tra xem đã có preset 'Frontend Performance' chưa.
Nếu chưa, hãy cài đặt skill 'vercel-labs/agent-skills' và kích hoạt cho workspace hiện tại.
Bảo toàn trạng thái an toàn

Khi agent tương tác thông qua Skills Manager CLI, toàn bộ metadata, đường dẫn nguồn gốc và phiên bản cập nhật đều được bảo toàn nguyên vẹn trong cơ sở dữ liệu, không làm hỏng cấu trúc thư mục của agent.
