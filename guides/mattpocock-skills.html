Matt Pocock Skills — Kỹ thuật phần mềm thực thụ cho Coding Agent

Bộ skill tinh gọn, có khả năng kết hợp cao do Matt Pocock (Total TypeScript) phát triển. Khắc phục 4 điểm gãy kinh điển của coding agent: lệch pha yêu cầu, agent giải thích dông dài, code sinh ra không chạy được và biến codebase thành bãi rác phức tạp.

mattpocock/skills · 305k ★ Tác giả: Matt Pocock · Giấy phép MIT Mã nguồn GitHub chính thức

1. Tổng quan: Vấn đề & Giải pháp

Trào lưu "vibe coding" (gõ prompt mơ hồ rồi hy vọng AI đoán đúng ý) tạo ra ảo giác tiến độ nhanh lúc đầu, nhưng nhanh chóng dẫn đến bế tắc khi codebase phình to. Matt Pocock Skills đưa các nguyên lý công nghệ phần mềm kinh điển vào agent:

Vấn đề thường gặp Hậu quả thực tế Giải pháp bằng Skill
Agent làm sai ý bạn Code xong mới nhận ra agent hiểu sai nghiệp vụ cốt lõi. Dùng /grill-me hoặc /grill-with-docs để agent chất vấn ngược lại bạn đến tận cùng trước khi code.
Agent nói dông dài tốn token Agent suy đoán thuật ngữ của dự án, dùng 20 từ thay vì 1 từ. Tự động xây dựng bảng thuật ngữ GLOSSARY.md và ADRs (Architectural Decision Records).
Code sinh ra không chạy được Không có vòng lặp kiểm chứng (flying blind). Kỹ năng /tdd: Viết test đỏ trước, viết code xanh sau, refactor cuối cùng.
Codebase thành "đống bùn" Các module phụ thuộc chéo, kiến trúc bị vỡ. Kỹ năng /improve-codebase-architecture khảo sát các cơ hội làm sâu module (deep modules).

2. Quy trình làm việc trực quan (5 bước chuẩn mực)

Sơ đồ luồng phát triển phần mềm có kỷ luật với Coding Agent
Bước 1

Phỏng vấn làm rõ

Chạy /grill-with-docs. Agent hỏi xoáy vào các ca biên, cập nhật GLOSSARY.md.

Bước 2

Đặc tả kỹ thuật

Chạy /to-spec để tổng hợp kết quả phỏng vấn thành spec kỹ thuật hoàn chỉnh.

Bước 3

Phân rã Tickets

Chạy /to-tickets để bẻ spec thành các ticket độc lập có khai báo quan hệ phụ thuộc.

Bước 4

Triển khai TDD

Chạy /implement. Agent áp dụng TDD red-green-refactor qua từng slice nhỏ.

Bước 5

Review & PR

Kích hoạt /code-review (soi tiêu chuẩn & spec) rồi tạo PR chuẩn mực với /pr.

3. Phân loại kỹ năng: User-invoked vs Model-invoked

User-invoked
Do bạn trực tiếp gõ lệnh để điều phối luồng làm việc lớn: /grill-with-docs, /to-spec, /to-tickets, /implement, /improve-codebase-architecture, /wayfinder, /handoff.
Model-invoked
Do agent tự động vươn tới khi cần để giữ vững kỷ luật kỹ thuật: tdd (vòng lặp viết test), diagnosing-bugs (chẩn đoán lỗi), codebase-design (thiết kế module sâu), code-review, prototype, research.

4. Hướng dẫn cài đặt & Thiết lập dự án

Cài đặt 1 dòng lệnh

Chọn công cụ agent bạn đang sử dụng

bash — Claude Code 
claude plugin install mattpocock-skills@claude-plugins-official
bash — Cursor / OpenCode / Windsurf (qua npx) 
npx skills@latest add mattpocock/skills -a cursor
Hành động bắt buộc sau khi cài đặt:

Trong cửa sổ chat với agent, hãy gõ /setup-matt-pocock-skills một lần duy nhất cho mỗi repository. Agent sẽ hỏi bạn: sử dụng issue tracker nào (GitHub, GitLab hay file cục bộ), quy ước nhãn triage và nơi lưu tài liệu kiến trúc.

5. Ví dụ thực tế: Dùng /grill-me làm rõ tính năng mới

Prompt gửi cho Agent 
/grill-with-docs Tôi muốn bổ sung tính năng xuất dữ liệu báo cáo ra file PDF có kèm chữ ký số.
Hãy đóng vai kiến trúc sư trưởng khó tính, phỏng vấn tôi từng kịch bản người dùng, ca biên, cơ chế cấp phát khóa và cập nhật GLOSSARY.md.

6. Lưu ý quan trọng

Tránh cài đặt trùng lặp

Nếu đã cài qua Plugin Manager của Claude Code hoặc Codex, đừng chạy thêm lệnh npx skills. Việc cài cả hai sẽ khiến agent nạp mọi kỹ năng 2 lần, gây lãng phí context window và xung đột lệnh.

Tập tin GLOSSARY.md

Tập tin GLOSSARY.md được tạo ra ở thư mục gốc giúp agent tiết kiệm 30-40% lượng token suy nghĩ mỗi session vì mọi định danh hàm, biến và khái niệm kinh doanh đều được dùng thống nhất.
