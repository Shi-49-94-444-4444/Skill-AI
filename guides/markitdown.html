Microsoft MarkItDown — Tối ưu 80% Token Tài Liệu cho Coding Agent

Giải pháp xử lý tài liệu mã nguồn mở từ Microsoft Research (hơn 180.000 sao). Khắc phục cơ chế "tính tiền hai lần" ngầm định của Claude khi đọc PDF (vừa đọc chữ vừa nạp ảnh chụp từng trang), nén dung lượng ngữ cảnh và hỗ trợ MCP Server tự động chuyển đổi file.

microsoft/markitdown · 180k ★ Tác giả: Microsoft Research · Giấy phép MIT Mã nguồn GitHub chính thức
Mục đích chính Tiết kiệm 80-90% Token Ngăn chặn việc nạp ảnh thừa khi đọc tài liệu văn bản thông thường.
Dành cho ai Người dùng Claude & Developer Thường xuyên phân tích hợp đồng, báo cáo, file Excel và tài liệu dày.
Thời gian làm quen ~5 Phút Chỉ cần sao chép một dòng lệnh pip install markitdown.
Hành động cốt lõi Chuẩn hóa sang Markdown Bảo toàn bảng biểu, cấu trúc heading và trích xuất dữ liệu sạch.

// 01 · TỐI ƯU HÓA TOKEN TÀI LIỆU (DOCUMENT TOKEN COMPRESSION ENGINE): Sắc xanh Microsoft Azure phối hợp đen than kỹ thuật, loại bỏ gánh nặng nạp ảnh trang và giải phóng cửa sổ ngữ cảnh cho agent.

1. Bảng đối chiếu: Vì sao PDF nguyên bản làm tiêu hao lượt dùng nhanh chóng?

Theo tài liệu chính thức từ Anthropic, khi người dùng tải lên một tệp PDF, hệ thống thực hiện hai bước xử lý song song: chuyển từng trang thành ảnh chụp độ phân giải cao và rút trích phần chữ. Người dùng phải trả chi phí cho cả hai:

Thành phần Kéo thả file PDF trực tiếp Chuyển đổi qua MarkItDown trước
Cơ chế nạp vào AI Nạp cả ảnh chụp trang (image tokens) lẫn phần chữ rút ra (text tokens). Chỉ nạp chữ thuần định dạng Markdown sạch sẽ (Pure Text Markdown).
Tài liệu 20 trang Tốn từ 60.000 đến 120.000 token trước khi đặt câu hỏi đầu tiên. Chỉ tốn từ 6.000 đến 10.000 token (giảm hơn 85% chi phí).
Giới hạn trang Giới hạn nghiêm ngặt 100 - 600 trang hoặc 32MB trước khi bị tràn context. Không bị giới hạn số trang của vision; tài liệu dày 500 trang vẫn đọc mượt mà.
Tốc độ xử lý của AI Chậm vì phải chạy mô hình Vision để phân tích ảnh từng trang. Cực nhanh vì chỉ xử lý văn bản có cấu trúc phân cấp rõ ràng.
Nhấp để phóng to
// 02 · CẮT GIẢM CHI PHÍ TOKEN (TOKEN BUDGET OPTIMIZATION): Chuyển hóa 60.000 token hỗn hợp ảnh + chữ thành 8.000 token Markdown nguyên bản, giữ trọn vẹn ngữ cảnh hội thoại dài hạn.

4. Các phương thức tích hợp vào công việc hàng ngày

Chuyển đổi một file nhanh chóng

Gõ markitdown tailieu.pdf > tailieu.md. File markdown được tạo ngay tại thư mục hiện tại để bạn mở xem hoặc gửi cho AI.

Chuyển đổi hàng loạt toàn bộ thư mục

Dùng script bash hoặc powershell một dòng để chuyển đổi toàn bộ file hợp đồng và báo cáo quý thành các file .md tương ứng.

Tích hợp vào Claude Desktop qua MCP

Khai báo MarkItDown MCP server trong claude_desktop_config.json. Từ đó mỗi khi bạn nhắc đến file trên máy, Claude tự gọi MarkItDown để chuyển sang chữ thuần trước khi đọc.

Nhúng vào ứng dụng hoặc agent tự động

Dùng thư viện Python chính thức với chỉ 3 dòng mã: from markitdown import MarkItDown; md = MarkItDown(); result = md.convert("input.xlsx").

5. Bắt đầu với MarkItDown trong 3 bước

1

Cài đặt gói công cụ qua pip

Mở Terminal (Mac) hoặc PowerShell / CMD (Windows) và dán lệnh sau:

Bash · Cài đặt MarkItDown 
pip install markitdown
2

Chuyển đổi thử một tệp PDF hoặc Word

Chuyển tệp tài liệu văn phòng bất kỳ sang định dạng markdown sạch:

Bash · Chuyển đổi file 
markitdown baocao.pdf > baocao.md
3

Nạp tệp .md vào Claude hoặc Agent

Kéo tệp .md vừa tạo vào khung chat để làm việc với tốc độ phản hồi cực nhanh và tiết kiệm hơn 80% hạn mức token.

Khi nào KHÔNG nên dùng MarkItDown?

Nếu tài liệu của bạn chứa biểu đồ thị giác phức tạp, sơ đồ hình học hoặc chữ ký tay mà bạn cần AI phân tích hình dáng trực quan, hãy tải thẳng file PDF gốc để Claude kích hoạt bộ đọc Vision. Với tất cả tài liệu dạng văn bản, báo cáo số liệu và hợp đồng, hãy luôn dùng MarkItDown để tối ưu chi phí.
