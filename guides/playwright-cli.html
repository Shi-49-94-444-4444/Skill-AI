Playwright CLI — Trao cho AI Agent đôi mắt và đôi tay trên Trình duyệt

Công cụ dòng lệnh chính thức từ Microsoft cho phép AI coding agent tự động tương tác trực tiếp với trình duyệt web: mở trang, chụp ảnh màn hình, tương tác với các phần tử, trích xuất cây khả năng tiếp cận (Accessibility Tree) và tự động sinh mã kiểm thử E2E.

Công cụ cho agent Tổ chức: Microsoft Giấy phép: Apache-2.0 Ngôn ngữ: TypeScript GitHub Repository (14.7k+ ★)
1. Tổng quan 2. Các tính năng chính 3. Lệnh CLI cơ bản thường dùng 4. Cách Agent sử dụng để tự kiểm tra UI 5. Tự động sinh mã kiểm thử (Codegen) 6. Tài liệu & Nguồn gốc

1. Tổng quan: Đây là gì và giải quyết vấn đề gì?

Khi lập trình viên yêu cầu AI viết mã frontend (HTML/CSS/JS/React), một trong những hạn chế lớn nhất là agent không thực sự nhìn thấy trang web trông như thế nào sau khi chạy. Agent chỉ đoán giao diện qua mã nguồn, dẫn đến việc các phần tử bị che khuất, nút bấm bị tràn màn hình hoặc luồng người dùng bị kẹt mà không ai hay biết.

Microsoft Playwright CLI cung cấp một giao diện dòng lệnh đơn giản, chuẩn hóa để agent có thể khởi động trình duyệt thật (Chromium, Firefox, WebKit), điều hướng đến URL cục bộ, chụp ảnh màn hình để tự soi lỗi, click vào các nút bấm để kiểm tra tương tác và trích xuất thông tin DOM một cách chuẩn xác.

Engine trình duyệt Chromium, Firefox, WebKit
Chế độ vận hành Headless (chạy ngầm) & Headed (mở cửa sổ)
Chụp ảnh màn hình Fullpage, Viewport, Element Selector
Tích hợp sẵn Antigravity, Claude Code, GitHub Actions

2. Các tính năng kỹ thuật nổi bật

Tính năng Khả năng kỹ thuật Ứng dụng cho Agent
Screenshot Snapshot Chụp ảnh màn hình toàn trang hoặc theo selector với các tùy chọn viewport (1440px desktop, 768px tablet, 390px mobile). Agent nạp ảnh vào vision model để kiểm định visual layout trước khi bàn giao.
Accessibility Tree Trích xuất cây ARIA/Accessibility Snapshot dưới dạng text có cấu trúc. Agent kiểm tra tính khả dụng cho người khuyết tật mà không cần nạp toàn bộ DOM nặng nề.
Codegen (Ghi mã tự động) Mở trình duyệt, theo dõi thao tác chuột/bàn phím của người dùng và dịch trực tiếp thành mã test Playwright (TS/JS/Python). Viết test tự động siêu tốc chỉ bằng cách click thao tác trên web.
Thực thi kịch bản CLI Hỗ trợ click, type, press key, wait-for-selector trực tiếp từ các lệnh dòng lệnh ngắn gọn. Agent tự động điền form, kiểm tra luồng login và xác minh chức năng.

3. Các lệnh CLI cơ bản thường dùng

1. Chụp ảnh màn hình trang web

bash 
# Chụp ảnh toàn trang ở chế độ desktop
npx playwright screenshot --full-page http://localhost:3000 screenshot.png

# Chụp ảnh giả lập màn hình iPhone 14
npx playwright screenshot --device="iPhone 14" http://localhost:3000 mobile.png

2. Trích xuất cây Accessibility Tree để agent đọc

bash 
npx playwright-cli snapshot http://localhost:3000 --output tree.json

3. Kiểm tra mã phản hồi HTTP và console error

bash 
npx playwright-cli check-errors http://localhost:3000

4. Chu trình Agent tự kiểm tra và sửa lỗi UI (Look-and-Fix Loop)

Khi được tích hợp kỹ năng Playwright CLI, agent có thể chạy vòng lặp hoàn thiện giao diện tự động:

1

Khởi động máy chủ cục bộ & Chụp ảnh

Agent chạy server test và dùng playwright screenshot để chụp ảnh giao diện ở 3 kích thước: 1440px (Desktop), 768px (Tablet) và 390px (Mobile).

2

Quan sát và chấm điểm thị giác

Agent đọc hình ảnh chụp được, phát hiện các điểm lỗi: chữ tràn dòng, bảng dữ liệu bị che khuất, nút bấm bị lệch lề ngoài hoặc thiếu độ tương phản.

3

Chỉnh sửa CSS / HTML và chụp lại

Agent sửa mã nguồn và gọi lệnh chụp lại ngay lập tức để so sánh trực tiếp Before / After cho đến khi toàn bộ lỗi thị giác được triệt tiêu.

5. Tự động sinh mã kiểm thử với Codegen

Lệnh codegen là trợ thủ đắc lực giúp bạn tạo kịch bản kiểm thử tự động chỉ trong vài giây:

bash 
# Mở trình duyệt và tự động sinh code TypeScript
npx playwright codegen http://localhost:3000 --target typescript -o tests/e2e.spec.ts

Cửa sổ trình duyệt và cửa sổ Playwright Inspector sẽ hiện ra song song. Mọi thao tác gõ phím, click chuột, chọn dropdown của bạn sẽ được tự động chuyển thành mã code Playwright chuẩn chỉ.
