Playwright CLI — Trao "Đôi mắt & Bàn tay" cho AI Coding Agent

Bộ công cụ dòng lệnh chính thức do Microsoft phát triển giúp AI coding agent tương tác trực tiếp với trình duyệt web thật. Hỗ trợ chụp ảnh màn hình, kiểm tra cây trợ năng (Accessibility Tree) và thực hiện vòng lặp "Look-and-Fix" tự động sửa lỗi CSS/UI mà không cần con người can thiệp.

microsoft/playwright-cli · 7.4k ★ Tổ chức: Microsoft · Giấy phép Apache-2.0 Mã nguồn GitHub chính thức

1. Vòng lặp Look-and-Fix: Cơ chế tự sửa lỗi giao diện của Agent

Trước đây, AI viết CSS "trong bóng tối" (flying blind) vì không nhìn thấy kết quả render thực tế. Playwright CLI biến agent thành một tester chuyên nghiệp với chu trình khép kín:

1. Render Mở trang Headless

Agent kích hoạt trình duyệt Chromium ngầm truy cập vào localhost:3000.

2. Inspect Chụp ảnh & Cây a11y

Chụp ảnh màn hình độ phân giải cao và trích xuất cấu trúc Accessibility Tree gọn nhẹ.

3. Fix Sửa mã nguồn

Phát hiện chữ bị tràn (overflow) hoặc nút bấm lệch margin để chỉnh sửa lại file CSS.

4. Verify Kiểm chứng kết quả

Chụp lại ảnh màn hình mới, so sánh diff trực quan để xác nhận lỗi đã biến mất hoàn toàn.

2. Bảng tra cứu các lệnh Playwright CLI quan trọng

Lệnh CLI Ý nghĩa hoạt động Lợi thế vượt trội cho AI Agent
playwright-cli screenshot <url> Chụp ảnh màn hình trang web Lưu ảnh dạng PNG để mô hình AI Multimodal (Claude 3.5/Opus, GPT-4o) nhìn thấy pixel thật.
playwright-cli snapshot <url> Trích xuất cây Accessibility Tree Cung cấp cấu trúc tương tác ngữ nghĩa, nhẹ hơn 90% so với việc gửi toàn bộ HTML DOM thô.
playwright-cli click <selector> Mô phỏng thao tác nhấp chuột Kiểm tra menu dropdown, mở modal, chuyển tab hoặc kích hoạt trạng thái hover.
playwright-cli fill <selector> <text> Điền dữ liệu vào form Tự động thử nghiệm các luồng nhập liệu phức tạp (Đăng ký, Đăng nhập, Checkout).
playwright-cli eval <script> Thực thi JavaScript trên trình duyệt Đo lường kích thước phần tử, lấy giá trị window.getComputedStyle chính xác.

3. Kịch bản kiểm tra giao diện tự động cho Agent

Bash · Quy trình kiểm tra Responsive trên 3 kích thước 
# Chụp ảnh giao diện trên Desktop (1440x900)
npx playwright-cli screenshot http://localhost:3000 --viewport-size 1440,900 --output ./desktop.png

# Chụp ảnh trên Tablet (768x1024)
npx playwright-cli screenshot http://localhost:3000 --viewport-size 768,1024 --output ./tablet.png

# Chụp ảnh trên Mobile (390x844 - iPhone 14)
npx playwright-cli screenshot http://localhost:3000 --viewport-size 390,844 --output ./mobile.png

4. Prompt kích hoạt Agent dùng Playwright CLI

Prompt · Yêu cầu Agent tự sửa lỗi giao diện 
Hãy mở trang web `http://localhost:3000` bằng Playwright CLI và thực hiện các bước sau:
1. Chụp ảnh màn hình viewport mobile 390px và kiểm tra xem thanh menu điều hướng có bị che mất nút Đăng nhập không.
2. Nếu bị che khuất, đọc file CSS liên quan để sửa lại thuộc tính z-index và flex-wrap.
3. Chụp lại ảnh màn hình mới và giải thích lý do tại sao phương án sửa chữa này giải quyết dứt điểm vấn đề.
Accessibility Tree: Bí quyết tiết kiệm token

Thay vì tải về hàng nghìn dòng mã HTML rối rắm chứa đầy thẻ <div> vô nghĩa, hãy ưu tiên dùng lệnh snapshot. Bạn sẽ nhận được cây trợ năng tinh giản chỉ gồm vai trò (button, link, heading) và nhãn chữ, giúp agent đưa ra quyết định nhanh hơn gấp 5 lần.
