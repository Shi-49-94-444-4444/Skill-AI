Playwright CLI — Tự Động Hóa Trình Duyệt Headless & Đôi Mắt Của Coding Agent

Bộ công cụ trao “đôi mắt thật” cho AI coding agent. Thay vì chỉ đọc code và đoán mò, Playwright CLI cho phép agent tự khởi chạy trình duyệt không đầu (Headless Chromium), chụp ảnh màn hình ở 4 kích cỡ viewport, bắt lỗi console rò rỉ và đo lường layout shift trước khi bàn giao sản phẩm.

microsoft/playwright · Chuẩn kiểm thử E2E Tác giả: Microsoft · Giấy phép Apache-2.0 Mã nguồn Playwright
Mục đích chính Đôi Mắt Của Agent Cho phép agent nhìn thấy giao diện thực tế như người dùng cuối.
Kiểm tra đa màn hình 4 Độ Phân Giải Mobile (375px/390px), Tablet (768px), Laptop (1024px), Desktop (1920px).
Bắt lỗi tự động Console & Network Chặn đứng các lỗi 404 hình ảnh, CSP violation và exception JavaScript.
Tốc độ thực thi Dưới 1 Giây Khởi động Chromium headless và chụp screenshot trong chớp mắt.

Bắt Lỗi Tràn Viền Ngang (Horizontal Overflow-X)

Hàm kiểm tra JavaScript so sánh document.documentElement.scrollWidth với clientWidth. Nếu lớn hơn dù chỉ 1px, agent sẽ tự động tìm phần tử gây tràn và sửa CSS max-width: 100%.
