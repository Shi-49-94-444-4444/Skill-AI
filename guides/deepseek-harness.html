DeepSeek Harness (dsh) — Nền tảng Agent Harness vạn năng từ DeepSeek AI

Môi trường điều phối agent mã nguồn mở do DeepSeek AI phát triển. Xây dựng trên triết lý "Mọi thứ đều là Plugin" (Everything is a Plugin) và nền tảng Cordis, cho phép khởi chạy giao diện Web UI mạnh mẽ hoặc vận hành thông qua CLI siêu tốc với khả năng mở rộng không giới hạn.

1. Tổng quan: Đây là gì và giải quyết vấn đề gì?

Các agent harness truyền thống thường bị đóng khung trong kiến trúc nguyên khối (monolithic): việc thêm một công cụ mới, đổi mô hình LLM, cấu hình proxy hay bổ sung bộ nhớ dài hạn đòi hỏi phải sửa đổi sâu vào mã nguồn của harness. Điều này tạo ra sự phân mảnh lớn trong hệ sinh thái AI agent.

DeepSeek Harness (dsh) được DeepSeek AI thiết kế để giải quyết bài toán này từ gốc rễ. Toàn bộ hệ thống — từ kết nối mô hình (LLM adapter), giao diện người dùng (Web UI/CLI), các công cụ thực thi mã, hệ thống lập lịch (scheduler) cho đến bộ nhớ ngữ cảnh — đều là các Plugin độc lập hoạt động trên nền tảng vi hạt nhân (microkernel) Cordis.

Kiến trúc hạt nhân Cordis Spatiotemporal Composability
Giao diện điều khiển Web UI (cổng 3080) & CLI tương tác
Hỗ trợ mô hình DeepSeek-V3/R1, OpenAI, Anthropic, Ollama, vLLM
Chuẩn giao tiếp công cụ Model Context Protocol (MCP) & Native Tools

2. Kiến trúc "Everything is a Plugin"

Dựa trên công trình nghiên cứu "A Programming Paradigm for Spatiotemporal Composability" (arXiv:2608.25512), Cordis cung cấp cho DeepSeek Harness khả năng nạp, tháo rời và liên kết các plugin trong thời gian thực mà không cần khởi động lại tiến trình:

Core

Cordis Microkernel & Event Bus

Trục truyền thông trung tâm xử lý đăng ký dịch vụ, phân phối sự kiện vòng đời agent (agent lifecycle events) và quản lý phạm vi ngữ cảnh (context scopes).

LLM

LLM Adapter Layer

Plugin chuẩn hóa các giao thức suy luận: hỗ trợ streaming tokens, xử lý ngắt kết nối tự động kết nối lại (active-stream-reconnect), thích ứng linh hoạt giữa API trả lời dạng văn bản và function calling.

Tools

Tool Registry & Sandboxed Execution

Nơi đăng ký công cụ tương tác tệp tin, thực thi terminal, duyệt web, kiểm tra an toàn (Safety confirmation guard) trước khi chạy lệnh phá hủy.

UI

Web UI & Session Management

Ứng dụng web hiện đại khởi chạy tại http://127.0.0.1:3080 cho phép quản lý nhiều phiên làm việc song song, xem đồ thị suy luận và cấu hình trực quan.

3. Các tính năng nổi bật của DeepSeek Harness

Phân hệ Khả năng kỹ thuật Lợi ích thực tế
Web UI & Remote Control Giao diện đồ họa đầy đủ tính năng, hỗ trợ chạy cục bộ hoặc qua kết nối SSH từ xa an toàn với cờ --no-open. Trải nghiệm làm việc trực quan, không bị gò bó trong dòng lệnh đen trắng truyền thống.
Chợ Plugin (Plugin Market) Cơ chế khám phá plugin thông qua nhãn dsh-plugin trên GitHub. Cài đặt và cập nhật plugin động chỉ với một click. Mở rộng công cụ của bên thứ ba dễ dàng như cài extension trên VS Code.
Cơ chế Khôi phục luồng Công nghệ agent-continuation và active-stream-reconnect bảo toàn trạng thái suy luận khi mạng chập chờn. Không bị mất dữ liệu hoặc hỏng phiên làm việc khi đang chạy các tác vụ kéo dài hàng giờ.
Network Proxy Hỗ trợ cấu hình proxy HTTP/HTTPS/SOCKS5 cấp độ nhân cho các môi trường mạng doanh nghiệp khắt khe. Làm việc ổn định sau tường lửa mà không cần hack cấu hình hệ thống.

4. Hướng dẫn cài đặt & Khởi chạy

Cách 1: Khởi chạy nhanh qua npx (Khuyến nghị)

Yêu cầu đã cài đặt Node.js (phiên bản 18+ hoặc 20+). Chỉ cần mở terminal và chạy lệnh:

bash 
npx @deepseek-ai/dsh web

Lệnh trên sẽ tự động khởi động máy chủ Web UI tại địa chỉ http://127.0.0.1:3080 và tự động mở trình duyệt mặc định của bạn.

Chạy trên VPS hoặc Server qua SSH

Nếu bạn triển khai trên máy chủ từ xa, hãy thêm tham số --no-open để tránh lỗi cố gắng mở trình duyệt trên giao diện headless:

npx @deepseek-ai/dsh web --no-open --port 3080 --host 0.0.0.0

Cách 2: Chạy từ mã nguồn Git

bash 
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
pnpm run build
pnpm dsh web

6. Tích hợp Model Context Protocol (MCP) & Bộ nhớ

Harness hỗ trợ cắm trực tiếp các máy chủ MCP để mở rộng năng lực dữ liệu của agent:

json 
{
  "mcpServers": {
    "sqlite-memory": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-sqlite", "--db-path", "./memory.db"]
    },
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/path/to/allowed/dir"]
    }
  }
}

Cơ chế persistent memory lưu trữ các đoạn hội thoại quan trọng và sự kiện dự án vào cơ sở dữ liệu vector hoặc SQLite, giúp agent nhớ được các quyết định kiến trúc qua nhiều ngày làm việc.
