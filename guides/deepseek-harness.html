DeepSeek Harness — Khung điều phối vi nhân cho DeepSeek V3 & R1

Bộ khung điều phối tác tử chính thức do đội ngũ DeepSeek AI phát triển. Ứng dụng kiến trúc vi nhân Cordis (Microkernel) để kết nối mô hình DeepSeek-V3 và DeepSeek-R1 với các công cụ thực thi terminal, quản lý tiến trình và giao diện web tương tác theo thời gian thực.

1. Kiến trúc Vi nhân Cordis (Microkernel Architecture)

Không giống như các thư viện agent nguyên khối (monolithic), DeepSeek Harness tách biệt nhân lõi siêu nhẹ (Cordis Core) khỏi các plugin công cụ và lớp giao tiếp mạng:

2. Lựa chọn Mô hình tối ưu cho từng tác vụ

Mô hình Thế mạnh cốt lõi Chi phí Token Tác vụ phù hợp nhất
DeepSeek-V3 Tốc độ sinh mã cực nhanh, văn phong tự nhiên, gọi công cụ (Tool calling) chuẩn xác. Rất thấp (Khoảng 1/10 so với GPT-4o). Viết code tính năng mới, tạo CRUD, viết unit test, tra cứu cú pháp và refactor nhẹ.
DeepSeek-R1 Suy luận sâu (Chain-of-Thought), phát hiện lỗi logic tiềm ẩn, giải toán và thuật toán phức tạp. Trung bình (Có thêm token suy luận trong thẻ <think>). Debug lỗi hóc búa, thiết kế kiến trúc phân tán, phân tích mã độc và tối ưu thuật toán.

3. Khởi chạy DeepSeek Harness trong thực tế

Bash · Khởi chạy Web Console 
# Thiết lập khóa bí mật
export DEEPSEEK_API_KEY="sk-your-deepseek-api-key"

# Khởi chạy giao diện Web Console trên cổng 3000
npx @deepseek-ai/dsh web

# Hoặc khởi chạy trên máy chủ từ xa (Remote Server) không tự mở trình duyệt
npx @deepseek-ai/dsh web --port 8080 --no-open
Bash · Chạy trực tiếp trong Terminal 
# Chạy phiên tương tác trực tiếp
npx @deepseek-ai/dsh cli --model deepseek-reasoner

# Yêu cầu giải quyết một ticket lỗi cụ thể
npx @deepseek-ai/dsh run "Tìm và sửa lỗi Memory leak trong worker.ts"
Mẹo tiết kiệm chi phí với DeepSeek Harness

Tận dụng tính năng bộ đệm ngữ cảnh (Context Caching) của DeepSeek API: khi gửi cùng một cây thư mục mã nguồn nhiều lần, chi phí đọc token được giảm tới 90%, giúp agent duyệt qua các repo hàng trăm nghìn dòng code với chi phí chỉ vài cent.
