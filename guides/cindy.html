Cindy — AI Companion Mã nguồn mở Đa thiết bị & Điều phối Agent

Cindy ("Consider it done") là trợ lý AI mã nguồn mở dùng được ngay sau khi cài đặt. Nối liền máy tính cơ quan, máy tính bàn tại nhà, laptop và điện thoại thông minh; cho phép điều khiển máy tính từ xa (remote desktop), chia sẻ model subscriptions và gom Claude Code, Codex, Pi vào một giao diện thống nhất.

Đa thiết bị & Agent Tổ chức: Cindy App Giấy phép: Apache-2.0 Nền tảng: Desktop & Mobile GitHub Repository (8.1k+ ★)

1. Tổng quan: Đây là gì và giải quyết vấn đề gì?

Lập trình viên và người dùng công nghệ thường làm việc trên nhiều thiết bị: máy tính công ty, máy tính ở nhà và điện thoại khi đang di chuyển. Trải nghiệm AI hiện nay bị xé lẻ: bạn không thể tiếp tục đoạn chat dang dở ở cơ quan khi đang ngồi xe bus, không thể dùng API key đã cấu hình trên PC nếu chỉ cầm điện thoại, và khi agent gặp lỗi cần can thiệp trực tiếp thì chat thông thường hoàn toàn bất lực.

Cindy giải quyết bài toán này bằng cách biến chính chiếc máy tính cá nhân của bạn thành một server an toàn mà không cần thuê máy chủ hay thiết lập cấu hình mạng phức tạp. Mọi thiết bị kết nối vào Cindy đều chia sẻ chung một phiên làm việc, chung bộ nhớ và quyền truy cập tài nguyên.

Kiến trúc kết nối P2P Device Link Protocol an toàn
Nền tảng hỗ trợ macOS, Windows, Linux, iOS, Android
Tích hợp Harness Claude Code, Codex, Pi Agent
Chi phí máy chủ 0đ (Tận dụng máy tính cá nhân làm máy chủ)

2. Cơ chế "Tất cả thiết bị — Một Cindy"

Khi các thiết bị được đăng nhập cùng một tài khoản Cindy và kích hoạt quyền phù hợp:

1

Tiếp nối công việc liền mạch (Work Continuity)

Mở phiên làm việc trên điện thoại, tiếp tục đoạn hội thoại đang chạy trên máy tính bàn, đọc và chỉnh sửa file của dự án mà không cần phải copy dữ liệu hay đẩy code lên git.

2

Chia sẻ tài nguyên suy luận (Model Sharing)

Tận dụng các gói đăng ký mô hình (subscription) hoặc mô hình cục bộ (Ollama/vLLM) đã cài trên máy tính mạnh ở nhà ngay từ chiếc điện thoại pin yếu hoặc laptop văn phòng.

3

Dẫn dắt đội ngũ Agent (Team of Agents)

Cindy cho phép điều phối nhiều agent phối hợp cùng nhau: một agent chuyên lập kế hoạch (planning), các sub-agent chạy song song để code, và một agent độc lập làm nhiệm vụ review nghiệm thu.

3. Gom các Harness hàng đầu vào một giao diện duy nhất

Thay vì phải mở nhiều cửa sổ terminal rời rạc, Cindy hỗ trợ 3 harness chính:

Harness Năng lực mang lại Cách Cindy tích hợp
Claude Code Quy trình lập trình mạnh mẽ từ Anthropic với khả năng duyệt tệp, chỉnh sửa đa dòng và chạy test tự động. Chạy engine của Claude Code dưới nền nhưng bọc ngoài bằng UI trực quan và công cụ đa thiết bị của Cindy.
Codex Luồng làm việc coding chuyên sâu, tối ưu cho các tác vụ sinh mã và refactor lớn. Hoạt động song song bên cạnh các agent khác trong cùng một phiên trao đổi.
Pi Agent mã nguồn mở siêu nhẹ, dễ mở rộng, hỗ trợ kết nối đa dạng nhà cung cấp mô hình. Được sử dụng làm engine mặc định khi người dùng muốn chạy các tác vụ nhanh hoặc dùng mô hình local.

4. Tính năng Remote Desktop tích hợp trên điện thoại

Khi chat thông thường không đủ để giải quyết vấn đề (ví dụ cần bấm xác nhận trên một popup hệ điều hành, nhập mã OTP hoặc xem lỗi hiển thị trên trình duyệt máy tính):

Remote Desktop chuyên dụng cho lập trình viên

Ứng dụng di động của Cindy tích hợp sẵn bộ điều khiển Remote Desktop tốc độ cao: truyền hình ảnh màn hình với độ trễ thấp, có bàn phím ảo đầy đủ phím chức năng lập trình (Ctrl, Alt, Esc, Tab, Arrow keys), cho phép bạn điều khiển máy tính thật sự từ bất cứ đâu.

5. Hướng dẫn cài đặt & Thiết lập

1. Cài đặt ứng dụng Desktop

Tải bộ cài đặt chính thức cho hệ điều hành của bạn từ website cindy.app/download (hỗ trợ file DMG cho macOS, Installer cho Windows và AppImage cho Linux).

2. Chạy từ mã nguồn qua pnpm

bash 
# Clone repo và cài đặt các phụ thuộc
git clone https://github.com/makecindy/cindy.git
cd cindy
pnpm install

# Khởi chạy bản Desktop Dev
pnpm run dev:desktop

3. Kết nối ứng dụng di động

Cài đặt ứng dụng Cindy trên iOS/Android, đăng nhập cùng tài khoản và quét mã QR hiển thị trong mục Device Link trên ứng dụng Desktop để ghép đôi thiết bị bảo mật.

6. Cơ chế Bảo mật & Quản lý dữ liệu

Tệp tin dự án luôn nằm trên máy tính của bạn

Cindy không đồng bộ toàn bộ ổ cứng lên đám mây. Quyền truy cập từ xa hoạt động theo yêu cầu (on-demand streaming); mã nguồn và tệp nhạy cảm vẫn được lưu trữ cục bộ trên máy tính của bạn, đảm bảo tính bảo mật và quyền riêng tư tuyệt đối.
