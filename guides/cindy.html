Cindy — Điều khiển AI Coding Agent trên Điện thoại & Máy tính bảng

Dự án mã nguồn mở biến chiếc điện thoại của bạn thành trung tâm điều khiển từ xa cho các AI coding agent. Tận dụng sức mạnh xử lý của máy trạm để code, kiểm thử và deploy, trong khi bạn duyệt diff, duyệt lệnh và theo dõi tiến độ ngay trên mobile qua mạng an toàn.

makecindy/cindy · 1.6k ★ Tác giả: Cindy Labs · Giấy phép MIT Mã nguồn GitHub chính thức
Mục đích chính Code Từ Xa Trên Mobile Theo dõi terminal, duyệt git diff và bấm Approve lệnh ngay trên điện thoại.
Kiến trúc Máy trạm + Mobile PWA Máy tính gánh tải nặng, điện thoại chỉ nhận luồng UI qua WebSockets.
Bảo mật kết nối Mã QR One-time Không mở port công khai, chạy trong LAN hoặc mạng riêng Tailscale.
Động cơ hỗ trợ Đa Engine Cắm Ngoài Hỗ trợ Claude Code, OpenAI Codex và Pi harness.

1. Mô hình Phân tán: Máy trạm Host & Thiết bị Di động

Thay vì chạy mô hình nặng trên điện thoại khiến máy nóng và nhanh hết pin, Cindy sử dụng kiến trúc phân tách rạch ròi:

Kiến trúc phân tán Client - Host: Máy trạm (Host Server) thực thi toàn bộ các mô hình tính toán nặng, trong khi thiết bị di động đóng vai trò trạm điều khiển nhẹ và phê duyệt thao tác từ xa an toàn.

2. Bảng đối chiếu 3 Động cơ Thực thi (Harness Engines)

Động cơ AI Ưu điểm nổi trội Tính năng tương thích trên Mobile
Claude Code Khả năng đọc hiểu codebase lớn xuất sắc, tự động tìm kiếm file và refactor đa module. Xem cây thư mục tệp tin, xem danh sách công cụ được gọi (FileRead, Grep, Bash) theo thời gian thực.
OpenAI Codex Tốc độ sinh mã nhanh, hỗ trợ mạnh các ngôn ngữ lập trình kịch bản và thuật toán. Nhập prompt bằng giọng nói (Voice-to-code) và gửi thẳng vào tiến trình đang xử lý.
Pi Harness Động cơ siêu nhẹ chạy cục bộ với các model Open Source (Ollama / DeepSeek). Hoạt động hoàn toàn Offline trong mạng nội bộ, không phụ thuộc vào internet công cộng.

3. Quy trình ghép nối 2 thiết bị trong 60 giây

1

Khởi động Cindy Server trên máy trạm

Mở terminal trên máy trạm của bạn tại thư mục dự án và chạy lệnh khởi chạy dịch vụ:

Bash · Khởi chạy Cindy 
npx makecindy start --port 4040 --engine claude-code
2

Quét mã QR bảo mật trên terminal

Terminal sẽ tự động in mã QR chứa token ủy quyền dùng một lần (One-time token). Mở camera điện thoại quét để mở ngay ứng dụng.

3

Theo dõi và phê duyệt lệnh từ xa

Bạn có thể di chuyển ra khỏi bàn làm việc, nhận thông báo khi có lệnh cần phê duyệt và bấm nút Approve trực tiếp trên màn hình cảm ứng.

Trải nghiệm lập trình tự do khi di chuyển

Với Cindy, bạn có thể bắt đầu một tác vụ refactor lớn trên máy trạm tại văn phòng, sau đó ra ngoài uống cà phê và chỉ cần mở điện thoại để duyệt các bài kiểm thử và xác nhận commit git khi agent hoàn thành.
