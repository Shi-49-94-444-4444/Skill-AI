Cloudflare Security Audit — Quy trình Kiểm toán Bảo mật 6 Pha cho Coding Agent

Bộ kỹ năng kiểm toán bảo mật mã nguồn mở chính thức của Cloudflare (hơn 53.000 sao). Tự động hóa quá trình rà soát lỗ hổng bằng kiến trúc đa agent độc lập: trinh sát kiến trúc, săn lỗ hổng theo sổ cái coverage ledger, phản biện bác bỏ (adversarial verification) và báo cáo chuẩn hóa không phụ thuộc môi trường.

1. Bảng đối chiếu: Rủi ro bảo mật truyền thống & Giải pháp Cloudflare

Khi yêu cầu một AI agent thông thường "kiểm tra bảo mật", agent thường sinh ra hàng loạt cảnh báo chung chung, thiếu căn cứ hoặc bịa đặt (hallucination). Cloudflare Security Audit giải quyết triệt để vấn đề này bằng cơ chế xác minh cơ học:

Vấn đề thường gặp Hậu quả thực tế Giải pháp bằng Cloudflare Skill
Báo động giả tràn lan Kỹ sư mất hàng giờ rà soát các lỗ hổng không hề tồn tại trong code. Mỗi nghi vấn được giao cho một Verifier Agent hoàn toàn mới, độc lập tìm cách bác bỏ nó trước khi ghi nhận.
Bỏ sót vùng mã nguy hiểm Agent chỉ đọc lướt các file quen thuộc, bỏ quên module IPC hoặc auth framing. Sổ cái độ phủ coverage-ledger.json theo dõi cơ học từng unit đã kiểm tra và tìm kiếm lỗ hổng theo chủ đích.

Mất dấu vết khi chạy lặp lại Mỗi lần chạy lại kiểm toán từ đầu, tốn token và bỏ qua tiến độ cũ. Tính kế thừa cộng dồn (additive runs): tận dụng ledger cũ, chỉ kiểm tra phần code mới thay đổi.

2. Quy trình kiểm toán 6 pha chuẩn Cloudflare

Sơ đồ luồng kiểm toán an ninh đa pha (Multi-phase Audit Pipeline)
Pha 1 Trinh sát kiến trúc

Lập bản đồ ranh giới tin cậy (trust boundaries), bề mặt đầu vào trong architecture.md và khởi tạo sổ cái coverage-ledger.json.

Pha 2 Săn lùng theo sổ cái

Điều phối các Hunter Agent độc lập rà soát theo từng đơn vị ledger, có Coverage Critic phát hiện điểm mù.

Pha 3 Xác minh đối kháng

Chuyển từng ứng viên lỗ hổng cho một Verifier Agent độc lập với nhiệm vụ chứng minh lỗ hổng đó là vô hiệu.

Pha 4 Xuất cấu trúc Schema

Ghi nhận kết quả vào findings.json và kiểm định bằng validate-findings.cjs.

Pha 5 Hậu kiểm độc lập

Agent mới độc lập kiểm tra lại toàn bộ dẫn chứng mã nguồn thực tế trước khi xuất bản.

Pha 6 Báo cáo trung lập

Tự động tổng hợp REPORT.md, FINDINGS-DETAIL.md và NEEDS-VALIDATION.md.

3. Minh họa trực quan: Mô hình Hunter vs. Independent Verifier

Sức mạnh lớn nhất của bộ skill nằm ở việc loại bỏ thiên kiến nhận thức bằng việc tách đôi tác vụ săn lùng và phản biện:

4. 10 Lớp tấn công chuyên sâu (Specialized Attack Classes)

HTTP Request Framing & Cache Poisoning

Rà soát các lỗi đồng bộ HTTP giữa reverse proxy và backend, rủi ro phân mảnh tiêu đề, cache key không đầy đủ gây lộ dữ liệu cá nhân giữa các người dùng.

Client-side DOM Injection & Prototype Pollution

Kiểm tra các luồng gán dữ liệu vào innerHTML, xử lý thông điệp postMessage thiếu kiểm tra nguồn gốc và ô nhiễm nguyên mẫu đối tượng.

Prompt Injection & Tool Hijacking

Săn lùng các lỗ hổng khi mô hình AI nhận đầu vào không tin cậy và tự động kích hoạt công cụ (Tool Call) có quyền ghi file hoặc thực thi lệnh shell.

Output Handling & Indirect Data Exfiltration

Ngăn chặn kẻ tấn công lợi dụng việc hiển thị định dạng Markdown hoặc render ảnh để bí mật gửi token phiên làm việc ra máy chủ bên ngoài.

Dependency Confusion & Malicious Packages

Kiểm tra cấu hình registry trong package.json, lockfile integrity và rủi ro bị chiếm quyền điều khiển qua các script postinstall.

IAM & Serverless Ingress Policy

Phân tích các file cấu hình Terraform, Cloudflare Workers wrangler.toml và kiểm toán quyền hạn tối thiểu (Least Privilege).

Memory Safety & Native Binary Analysis

Rà soát tràn bộ đệm (buffer overflow), use-after-free, uninitialized memory trong các thư viện native C/C++/Rust.

Desktop, Mobile & Local IPC

Phân tích kênh giao tiếp liên tiến trình (IPC) trong ứng dụng Electron, xử lý custom protocol URL (deep-links) và lỗ hổng webview bridge.

5. Triển khai kiểm toán an ninh trong 3 bước

1

Cài đặt skill vào coding agent

Cài đặt thông qua Skills CLI cho dự án hiện tại hoặc toàn cục hệ thống:

Bash · Cài đặt Cloudflare Security Audit 
npx skills add https://github.com/cloudflare/security-audit-skill --skill security-audit --global
2

Kích hoạt kiểm toán toàn diện mã nguồn

Mở phiên làm việc trong agent (Claude Code, Codex, Antigravity, Cursor) và ra lệnh kiểm toán:

Prompt · Chạy toàn diện 6 pha 
security audit this codebase, output to ~/audits/my-project
3

Xác thực kết quả độc lập bằng script zero-dependency

Xác minh tính hợp lệ cơ học của sổ cái và các bằng chứng trước khi chuyển cho đội SecOps:

Bash · Chạy kiểm định JSON Schema 
node validate-coverage-ledger.cjs ~/audits/my-project/coverage-ledger.json
node validate-findings.cjs ~/audits/my-project/findings.json
